# Security Policy & Vulnerability Disclosure

## 🔒 Commitment to Security
This repository is engineered for global mission-critical environments, including **Artificial Intelligence, Post-Quantum Cryptography (PQC), Quantum Information Systems (VQE/QML), and Decentralized Blockchain Infrastructure (Solana, EVM, Algorand)**.

Security, cryptographic integrity, and data protection are paramount.

## 🛡️ Supported Versions
We provide security patches for the latest active release branches:

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main` / `master`| :white_check_mark: |
| Latest Tagged    | :white_check_mark: |
| Older Versions   | :x:                |

## 🚨 Reporting a Vulnerability
If you discover a security vulnerability, private key leak, smart contract exploit vector, or cryptographic weakness (such as deviations from NIST FIPS 203 ML-KEM or FIPS 204 ML-DSA specifications):

1. **DO NOT file a public issue.**
2. Send a confidential report to the security contact:
   - **Repository Owner:** [GitHub Profile](https://github.com/elon00)
   - **Security Advisory:** Open a [Private Security Advisory](https://github.com/elon00) via GitHub Security tab.
3. Include:
   - Description of the vulnerability and attack vector.
   - Proof-of-Concept (PoC) or reproducible steps.
   - Target network / runtime (e.g., Solana Devnet/Mainnet, Sepolia, Localhost).
   - Any suggested remediation.

## 💰 Responsible Disclosure & Bounties
We adhere to standard responsible disclosure principles (90-day embargo). We highly value community white-hat researchers and prioritize reviewing disclosures promptly.
